# Brigade's product vision

Stated by the chef on 2026-11-07. Written down by the second.

## Where we are

The kitchen keeps all its state on GitHub. A cook takes a `fire` ticket and the pass merges the result. Each ticket waits about five minutes between the moment it is claimed and its merge. But Brigade still needs a watcher: a routine relaunches tickets that the kitchen sets aside and could have repaired itself.

## Medium term: autonomy

The motto is **autonomy**. The chef leaves Brigade running and never fears it will stop on a trivial problem two hours later. Brigade works through everything it can do, and it calls a human only for a product or design choice, or for a review that only a human can make.

This is a goal of the process itself, **for every project added to Brigade**, not a tweak to one repository.

- **The kitchen heals itself** (#2745). Anything a routine or a human does by hand to keep the kitchen moving becomes the kitchen's own job:
  - relaunch a set-aside ticket that a cook can fix;
  - release a stale claim;
  - complete a ticket that misses something technical;
  - close a finished epic;
  - report a loop or an idle kitchen.
- **The app tells the chef when Brigade needs them, and only then.** The chef is less and less at the computer while Brigade works, so the app, Android first, becomes central:
  - step 1: a GitHub mention on each TODO card, so that GitHub Mobile sends the notification (#2746);
  - the goal: the app's own notification, which opens the card on tap (#2747).

## Long term: any project, on its own, for solos and teams

You create a project, you talk with the second, and development moves on without you. Brigade only brings you the choices you must make.

- **Solo developers.** That is the chef today.
- **Teams: humans are treated like stations** (#2748). Each human has their own skills, and **their role depends on the project**: product, design, review, client contact. Brigade assigns each question to the right human on GitHub and notifies them. Each human sees and answers their own cards in the app.
- **Open source.** Teams work with GitHub as the only shared place: assignees, mentions, labels, and the configuration committed in the repo. Brigade adds no server.
- **Cloud stations** come last. They are the offer to sell: a kitchen that runs without a machine of your own.

## Order

1. The kitchen heals itself (#2745), and the GitHub mention (#2746).
2. A newcomer cooks their first project alone (#1908). Only then do we make Brigade known (#1546), because a first impression is not wasted on an install that fails.
3. Humans as stations (#2748) and the app's notifications (#2747).
4. Cloud stations.

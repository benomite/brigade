# Brigade's product vision

Stated by the chef on 2026-11-07. Written down by the second. Three horizons, in order.

## 1. Autonomy now

The motto is **autonomy**. The chef leaves Brigade running, it works through everything it can do, and it calls a human only for a product or design choice, or for a review that only a human can make.

- **The kitchen heals itself** ([#2745](https://github.com/benomite/brigade/issues/2745)): anything a routine or a human does by hand to keep the kitchen moving becomes the kitchen's own job.
- **The app tells the chef when Brigade needs them, and only then**: step 1 is a GitHub mention on each TODO card, so that GitHub Mobile sends the notification ([#2746](https://github.com/benomite/brigade/issues/2746)); the goal is the app's own notification, which opens the card on tap ([#2747](https://github.com/benomite/brigade/issues/2747)).

## 2. Humans as stations

Humans are treated like stations. Each human has their own skills, and their role depends on the project.

- **Teams** ([#2748](https://github.com/benomite/brigade/issues/2748)): "humans are treated like stations"; Brigade assigns each question to the right human on GitHub and notifies them.

## 3. Any project run on its own, later

Later, you create a project, you talk with the second, and development moves on without you. Brigade only brings you the choices you must make.

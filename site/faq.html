brigade

Frequently asked questions

What is Brigade?

Brigade is a free, open-source app that runs Claude Code agents on your GitHub issues. The agents open, review and merge pull requests on their own, and ask you only for product decisions.

Who is it for?

It is for people who already use Claude Code and have a GitHub repository with a backlog of issues. It suits a solo developer or a small team who want tickets to ship while they are away from the computer.

What does it cost?

Brigade itself costs nothing: no licence, no seat, no per-ticket fee. You pay your own Claude subscription, and your hosting provider if you run a cloud machine. See the pricing page.

What does it need?

It needs a GitHub account with a repository, and a Claude subscription for the agents to run on. The desktop app runs on Mac (Apple silicon) and Windows.

How is it different from running Claude Code by hand?

By hand, you start a session, steer it and review its work yourself. With Brigade, you label an issue and an agent works it in its own git worktree, then an independent review and your checks run before it merges. You are called only when a product decision is yours.

How is it different from other ways of running several agents?

Brigade works from your GitHub issues and pull requests rather than from a chat or a script you drive. Each ticket gets its own agent and worktree, every delivery is judged by your gates, CI and a separate review before merging, and everything stays visible on GitHub.

- tmux never passes all of a fast output to the outer terminal, even on the normal screen (`smcup@:rmcup@`): it gathers what scrolls between two reads and writes only the last screen (3000 lines in, ~1100 out), so a tmux shell scrolls back through tmux's own history (copy mode driven from the tmux CLI, persistence.ts `scroll`), not through xterm.js's; `screen` passes every line (#4576)
- `screen` reads termcapinfo only from a `-c` rc file, and `screen -dmS` reads it at the first attach, not at creation: keep the rc in a 0700 user dir (`~/.brigade/screen`), never delete it right after `-dmS`, never a predictable /tmp name (#4576)
- tmux `set-option -t =name` (no colon) fails with "no such session" on the CI runner: target a session's options as `=name:` (#4576)
- No tmux on the cook's box and no apt: a static tmux from the `mjakob-gh/build-static-tmux` GitHub releases (`gh release download`) runs the real-multiplexer tests of app/test/persistence.test.ts with `PATH=<dir>:$PATH` (#4576)
